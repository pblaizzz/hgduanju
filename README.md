# hgduanju

片刻剧场：基于 [openhongguo](https://github.com/beilunyang/openhongguo) 的网页版短剧播放器，使用 Next.js、React 和 TypeScript。

## 本地运行

需要 Node.js 20.9+ 和系统 `curl`。FFmpeg 随 npm 平台包安装，无需另外安装到系统。

```sh
npm install
npm run dev
```

打开 [http://127.0.0.1:3100](http://127.0.0.1:3100)。默认读取真实红果片单；右上角可以切换到有明确标记的体验片单。

- [真实片单](http://127.0.0.1:3100/?source=live)
- [体验片单](http://127.0.0.1:3100/?source=demo)

## 已实现

- 首页推荐、内容类型切换、分页加载及重复条目去重。
- 搜索、搜索联想、热搜、短剧榜单。
- 剧集详情、分组选集、正序/倒序、不可播放集的提示。
- 播放、拖动进度、倍速、全屏、清晰度、上一集/下一集、自动连播。
- 当前浏览器的收藏、观看记录、断点续播；续播回退 3 秒。
- 手机、平板及桌面布局，键盘操作和减少动画偏好。
- 对上游 HEIC 封面做 JPEG 转换，避免浏览器不支持而丢失封面。

## 数据与播放

网页只访问本项目的 API。服务端使用 openhongguo 的匿名设备获取目录与播放模型，`curl` 传输层使用系统证书验证并保留压缩响应的原始字节，交给 SDK 解压。

真实播放使用项目内 FFmpeg，按需处理加密、独立音轨及浏览器不支持的视频编码，生成可拖动进度的 MP4；HTTP `Range` 支持 206 和 416 响应。播放地址和内容密钥不返回前端。

- `.cache/anonymous.json`：SDK 匿名设备档案，不要提交或分享。
- `archives/`：设备档案的加密快照与本地恢复说明；解密密钥仅保存在本机，不提交到仓库。
- `.cache/media/`：临时视频和不含密钥的缓存索引。有效期 30 分钟，下次准备视频时清理过期文件；已经准备好的视频会直接复用，避免重复请求上游。
- 观看记录及收藏存储在当前站点的 `localStorage`，不会跨浏览器或跨设备同步。
- 同时最多准备 2 个视频，单个 FFmpeg 任务超时 150 秒。首次播放和切换到尚未准备的清晰度需要等待。

本项目适合运行在有持久进程和可写磁盘的 Node.js 服务中。媒体准备依赖原生进程，不适合直接部署到受限的 Edge Runtime。

可复制 `.env.example` 为 `.env.local`。`NEXT_PUBLIC_DEFAULT_SOURCE` 可设为 `live` 或 `demo`，`FFMPEG_PATH` 可覆盖默认二进制路径。

## 检查

```sh
npm run typecheck
npm test
npm run build
npm start
```

16 项自动测试覆盖参数校验、体验片单、无效内容、Range 请求、本地记录恢复、连续观看逻辑、HEIC 封面转换、压缩响应及 Cookie 处理，以及用本地生成的 CENC 视频验证 FFmpeg 准备和媒体接口；不调用上游真实接口。

2026-10-30 的手动验证：真实首页、榜单与搜索返回了内容；一部短剧的首集在 Chromium 中以 1920×1080 播放，暂停刷新后从上次位置前 3 秒恢复。首集后续解析及第 2 集曾返回匿名访问限制；页面会提示，不会自动更换设备或跳过分集。体验片单验证了从第 1 集自动播放至第 6 集，并在末集停止。该结果不代表所有真实剧集、编码或浏览器均已验证。
